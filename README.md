# Bill Blast

Новое мобильное приложение для разделения счета в ресторанах поможет Вам удобно распределить счет между участниками, предлагая удобный и интуитивно понятный интерфейс.
Разработано для Сбербанка в рамках кейс-чемпионата ProЦифру.
____
## Структура проекта
Приложение разрабатывалось на Flutter, соответственно структура всего проекта свойственна любому обычному Flutter-приложению:
```
sber_split/  
├── android/                # Android-специфичный код    
├── ios/                    # iOS-специфичный код  
├── lib/                    # Основной код приложения
|   ├── main.dart           # Главная точка входа приложения
│   └── providers/          # Провайдеры состояния
│   └── screens/            # Экраны приложения  
│   └── services/           # Классы внешних библиотек  
│   └── models/             # Модели данных  
├── linux/                  # Linux-специфичная конфигурация  
├── macos/                  # macOS-специфичный код  
├── test/                   # Тесты  
├── web/                    # Web-сборка  
├── windows/                # Windows-сборка  
├── analysis_options.yaml   # Настройки анализатора Dart  
├── bump_server.py          # Серверная часть  
├── pubspec.lock            # Точные версии зависимостей  
├── pubspec.yaml            # Конфигурация проекта и зависимости   
├── requirements.txt        # Python-зависимости для сервера  
```
Особенно важным является файл __pubspec.yaml__, в котором указаны все необходимые зависимости проекта и их версии. Без этого файла, а точнее, без этих указанных зависимостей в файле, проект просто не будет запускаться. Все необходимые библиотеки устанавливаются автоматически, и о том как запустить приложение, будет рассказано ниже.

## Требования
Для работы приложения sber_split установлены следующие требования:
* Android 5.0 (API 21) и выше, iOS 12+.
* Устройства с акселерометром (для функции bump) и камерой (для сканирования чеков).
* Dart/Flutter (SDK 3.0+), Android NDK (версия 25.x).

Подробнее от минимальных версиях проекта указано в
* sber_split\android\app\build.gradle.kts
* sber_split\pubspec.yaml

Для контроля версий NDK и SDK удобно использовать Android Studio. Рекомендуется изначально собирать проект с установки этой программы и скачивания необходимых фреймворков.

## Настройка и отладка
У авторов проекта были установлены следующие параметры:
* Adnroid 15.0, 14.0, 13.0 (API Level 33-35)
* Android SDK Build Tools 34.0.0, 35.0.1, 36.0.0
* NDK (Side by Side) 27.0.12077973, 26.3.11579264 (версия 26.3 не обязательна к установке, хватит одной 27.0)

Указываем, поскольку, в случае непредвиденных ошибок у жюри, было на какие конкретные параметры ссылаться.
Для наглядности, у авторов были предустановлены следующие параметры (для Android Studio):

![SDK_NDK_Параметры](https://github.com/user-attachments/assets/246f36ea-a2c4-4ea5-a2d1-ab1f31710d7e)

Отладку можно проводить как в эмуляторах Android/Ios, так и в декстопной версии мобильного приложения.

![Встроенная отладка](https://github.com/user-attachments/assets/31b3fd8a-6f25-4446-9016-a7315f865cfe)

Для более быстрого просмотра результата использовалась в разработке отладка на Windows desktop, но в основном весь функционал отлаживался на реальных устройствах.
Чтобы запустить приложение с телефона, необходимо:
1. Активировать на мобильном устройстве отладку по usb (usb debugging) в разделе Для разработчиков,
2. Подключить телефон к компьютеру по usb, установив в сплывающем окне маркер на Передачу файлов,
3. запустить отладку с подключенным телефоном. Проект начнет собираться, а затем устанавливаться на устройство. После установки приложение запустится в режиме отладки, однако после отключения телефона от ПК, приложения будет запускаться уже в рабочем состоянии с полным функционалом.

Стоит учитывать, что для полной демонстрации работоспособности приложения лучше использовать несколько устройств одновременно (в связи с реализацией функции тряха, который позволяет разделить чек здесь и сейчас). Для распространения приложения можно либо аналогичным образом подключать устройства, либо передавать установленный .apk файл вручную (через Bluetooth, соц. сети). Переданный файл установится на Ваше устройство и будет готово к работе.

## Запуск приложения
Для того чтобы запустить проект (отладку), используется команда __flutter run__. Вводится она либо в терминале среды разработки, либо в командной строке из корневой папки проекта.

![flutter run](https://github.com/user-attachments/assets/820f035b-8a5a-4f87-a83c-7f5d70f18c0e)

Однако важно понимать, что перед первым запуском на устройстве не будет установлено необходимых пакетов и зависимостей, поэтому перед этим следует ввести команду __flutter pub get__. Это позволит запустить установку всех необходимых зависимостей, что описаны в файле __pubspec.yaml__.

![pub_get](https://github.com/user-attachments/assets/57074200-d6de-4b2e-ad08-1a4091d89c4f)

В случае различного рода ошибок, есть возможность удалить папку build и очистить кэш проекта по команде __flutter clean__. После нее необходимо заново указывать __flutter pub get__, поскольку все зависимости так же удаляются. Полезно, когда происходят непонятки с версиями и нужно внести правки в файле __pubspec.yaml__.
