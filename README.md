# Bill Blast

Новое мобильное приложение для разделения счета в ресторанах поможет Вам удобно распределить счет между участниками, предлагая удобный и интуитивно понятный интерфейс.
Разработано для Сбербанка в рамках кейс-чемпионата ProЦифру.

## Структура проекта
Приложение разрабатывалось на Flutter, соответственно структура всего проекта свойственна любому обычному Flutter-приложению:
```
sber_split/  
├── android/                # Android-специфичный код    
├── ios/                    # iOS-специфичный код  
├── lib/                    # Основной код приложения
|   ├── main.dart           # Главная точка входа приложения
│   └── providers/          # Провайдеры состояния
│   └── screens/            # Экраны приложения  
│   └── services/           # Классы внешних библиотек  
│   └── models/             # Модели данных  
├── linux/                  # Linux-специфичная конфигурация  
├── macos/                  # macOS-специфичный код  
├── test/                   # Тесты  
├── web/                    # Web-сборка  
├── windows/                # Windows-сборка  
├── analysis_options.yaml   # Настройки анализатора Dart  
├── bump_server.py          # Серверная часть  
├── pubspec.lock            # Точные версии зависимостей  
├── pubspec.yaml            # Конфигурация проекта и зависимости   
├── requirements.txt        # Python-зависимости для сервера  
```
Особенно важным является файл __pubspec.yaml__, в котором указаны все необходимые зависимости проекта и их версии. Без этого файла, а точнее, без этих указанных зависимостей в файле, проект просто не будет запускаться. Все необходимые библиотеки устанавливаются автоматически, и о том как запустить приложение, будет рассказано ниже.
